# Monolith lama (referensi)

Folder ini adalah backend monolith sebelum dimigrasi ke microservices. **Tidak dijalankan oleh `docker-compose.yml`.**
Disimpan sesuai prinsip migrasi "jangan langsung menghapus monolith": dipakai sebagai pembanding perilaku,
dan boleh dihapus setelah Anda yakin versi microservices berjalan baik.
